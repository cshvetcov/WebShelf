Ниже — подробное описание визуального языка, компонентов и принципов компоновки, извлечённое из предоставленного примера. Оно намеренно абстрагировано от конкретной функциональности (авторизации), чтобы его можно было переиспользовать для любых других окон приложения.
## 1. Общая философия

- **Тёмная десктопная эстетика**: приглушённые серо-угольные тона с акцентом в холодном бирюзово-зелёном (teal).
- **Имитация нативного окна ОС**: карточка с заголовком и рабочим контентом, как в Windows-приложении, но в браузере. Если есть необходимость закрывать окно (для отмены действия) в правой части заголовка необходимо предусмотреть кнопку закрытия с "крестиком". 
- **Сдержанная глубина**: тени и полупрозрачные границы создают объём без излишеств.


Переход начинается только во второй половине, создавая преимущественно тёмную поверхность с лёгким акцентом в углу.

## 6. Компоненты

### 6.1 Заголовок окна (`title-bar`)

**Структура:** горизонтальный flex-контейнер с зазором `0.45rem`.

**Содержимое:**

1. **Мини-иконка** (`title-icon`) — квадрат `16×16px` с градиентом и буквенным идентификатором (2 буквы, 700 веса).
2. **Текст заголовка** — название окна.

**Поведение:**

- Курсор `grab` / `grabbing` — намёк на перетаскивание.
- Тёмный фон `#2E2E30` с нижней границей для визуального отделения от карточки.
- При клике удерживается (`e.preventDefault()`), чтобы не выделять текст.
### 6.2 Карточка контента (`*-card`)

**Структура:** обёртка с градиентным фоном и внутренними отступами.

**Правила:**

- Обязательно использует диагональный градиент `#414042 → #0A5966`.
- Содержит все интерактивные элементы.
- `user-select: none` на уровне окна, но `user-select: text` принудительно для полей.
- `overflow: hidden` — содержимое не выходит за скруглённые углы.

### 6.3 Поле ввода (`input`)

**Структура:** `.input-wrapper` (relativ) → `<input>` + опциональная `.toggle-action` (absolute).

**Состояния:**

|Состояние|Фон|Граница|Эффект|
|---|---|---|---|
|Обычное|`rgba(0,0,0, 0.28)`|`rgba(255,255,255, 0.12)`|—|
|Фокус|`rgba(0,0,0, 0.38)`|`rgba(10,89,102, 0.8)`|`0 0 0 3px rgba(10,89,102, 0.25)`|

**Вложенная кнопка действия** (например, «показать/скрыть», «очистить», «скопировать»):

- Позиция: `absolute`, `right: 0.7rem`, вертикально центрирована.
- Размер: `1.6rem × 1.6rem`.
- Текст-иконка: `1.15rem`.
- `padding-right` у поля `2.8rem`, чтобы текст не налезал.
- Перечёркивание (для toggle-состояний) — отдельный `::after` элемент в виде линии `1.35rem × 1.5px`, повёрнутый на `-40deg`.

### 6.4 Кнопка действия (`btn-*`)

**Варианты:**

- **Primary** — сплошной фон `#0A5966`, белый текст, тень, hover `#0C6A7A`.
- Опционально: **secondary, ghost** — прозрачный фон + белая граница.

**Состояния:**

|Состояние|Поведение|
|---|---|
|Default|Тень `0 4px 14px`, фон `#0A5966`|
|Hover|Фон `#0C6A7A`, тень `0 6px 18px`|
|Active|`transform: scale(0.98)` — лёгкое «сжатие»|
|Disabled|`opacity: 0.55`, `cursor: not-allowed`, интерактив выключен|

**Анимация переходов:** `transform 0.15s`, `box-shadow 0.2s`, `background-color 0.2s`.

### 6.5 Статусное сообщение (`message`)

**Поведение:** скрыто по умолчанию (`display: none`), появляется только при наличии класса `.error` или `.success`.

**Свойства:**

- Центрированный текст, `0.85rem`.
- Полупрозрачный фон в тон статуса.
- Тонкая полупрозрачная граница.
- Отступ сверху `1.1rem` — отделяет от кнопки.
- Атрибут `role="alert"` для доступности.

## 7. Интерактивность и поведение

### 7.1 Перетаскивание окна

- Активируется по `mousedown` / `touchstart` на `title-bar`.
- Окно позиционируется через `left`/`top` (абсолютные координаты).
- При изменении размера окна (`resize`) или при первой загрузке — центрируется через JS.
- Поддержка как мыши, так и тач-устройств.
- Курсор документа принудительно меняется на `grabbing` на время перетаскивания.

### 7.2 Переходы (transitions)

Все интерактивные элементы имеют плавные переходы длительностью `0.15s–0.2s`:

- Поля ввода: `border-color`, `background`, `box-shadow`
- Кнопки: `transform`, `box-shadow`, `background-color`
- Toggle-иконки: `color`
- Скрытие/показ сообщений: реализуется через `display` (можно добавить `opacity` + `transform` для плавности)

### 7.3 Адаптивность (только как пример, зависит от контента)

|Брейкпойнт|Изменения|
|---|---|
|`≤ 480px`|Padding body `1rem`, окно `100%`, padding карточки `1.6rem 1.4rem 1.5rem`|
|`≥ 768px`|Окно расширяется до `420px`|
## 8. Принципы компоновки новых окон

1. **Всегда двухуровневая структура:** `title-bar` сверху + `*-card` снизу. Исключение — только для модальных уведомлений без заголовка.
2. **Единый градиент на карточке** — это фирменный признак стиля, не использовать одноцветные фоны для рабочих областей.
3. **Форма как список «полей + подписи»**, без декоративных группировок.
4. **Иконка в заголовке** = двухбуквенный идентификатор модуля на градиентном квадрате `16×16`.
5. **Статусные сообщения** — всегда внизу формы, над кнопкой или под ней; не плавающие тосты.
6. **Все интерактивные элементы имеют визуальный отклик**: hover, active, focus, disabled — ни одно состояние не должно быть немым.
