## 1. Как читать требование

Требование состоит из четырёх обязательств:

| # | Обязательство | Что это значит на практике |
|---|---|---|
| 1 | Платформа | `net10.0` и C# 14 (версия языка по умолчанию для .NET 10, `LangVersion` не понижать) |
| 2 | Приоритет современного | «Строго»: если есть современный эквивалент с той же семантикой, устаревшая форма считается замечанием на ревью |
| 3 | Лаконичность | Убирать церемонии (служебные поля, временные переменные, ручные проверки), но не превращать код в «код-гольф» |
| 4 | Явная типизация | В объявлениях тип указан явно, `var` не используется (см. раздел 3) |

**Границы применения:**

- Правило действует для нового и изменяемого кода. Массовый рефакторинг старого кода делается отдельной задачей.
- Семантика не меняется. Например, `[..]` для `IEnumerable<T>` и для `List<T>` даёт разные объекты, поэтому целевой тип выбирается осознанно.
- Preview-возможности (C# 15 / .NET 11) вне рамок.
- Отступить от правила можно, только если современная форма ухудшает читаемость, производительность или корректность. Причину фиксируют комментарием.

## 2. Карта возможностей по версиям

C# 14 — актуальная версия языка, она поддерживается на .NET 10. Возможности более ранних версий тоже входят в требование.

| Версия | .NET | Ключевые возможности |
|---|---|---|
| **C# 14** | 10 | `extension`-блоки (extension members), `field`, null-conditional assignment (`a?.B = x`), неявные span-конверсии, `nameof(List<>)`, параметры лямбд с модификаторами без типов, partial-конструкторы и partial-события, пользовательские составные операторы (`+=`), file-based apps (`dotnet run app.cs`, директивы `#:`) |
| **C# 13** | 9 | `params` для коллекций и span, `System.Threading.Lock`, `\e`, неявный индекс `^` в инициализаторах, partial-свойства и индексаторы, `allows ref struct`, `OverloadResolutionPriority` |
| **C# 12** | 8 | primary constructors для любых типов, collection expressions, `using`-алиасы для любых типов, значения по умолчанию в параметрах лямбд, `ref readonly`, `[InlineArray]` |
| **C# 11** | 7 | raw string literals, `required`, list patterns, `"..."u8`, generic math, `file`-типы, переводы строк внутри `{}` интерполяции |
| **C# 10** | 6 | file-scoped namespace, global usings, `record struct`, extended property patterns, const-интерполяция, `CallerArgumentExpression` |
| **C# 9** | 5 | records, `init`, top-level statements, target-typed `new()`, `is not` / `and` / `or`, relational patterns |
| **≤ C# 8** | | switch-выражения, `using`-объявления, индексы и диапазоны, `??=`, nullable reference types, async streams, кортежи, локальные функции, `?.`, интерполяция, `nameof` |

## 3. Явная типизация: правила для примеров и кода

**Основное правило:** `var` не используется нигде. Это касается локальных переменных, `foreach`, `using`, `out`, деконструкции и `var`-паттерна.

```csharp
// ❌ неявная типизация
var names = new List<string>();
foreach (var name in names) { }
if (int.TryParse(text, out var number)) { }
var point = new { X = 1, Y = 2 };      // анонимный тип нельзя назвать явно
var square = (int x) => x * x;         // natural type лямбды

// ✅ явная типизация
List<string> names = [];
foreach (string name in names) { }
if (int.TryParse(text, out int number)) { }
(int X, int Y) point = (1, 2);         // или record Point(int X, int Y)
Func<int, int> square = x => x * x;
```

> [!note] Как трактуется правило
> - `new()` с целевым типом допустим. Тип явно записан слева, а справа убрано дублирование: `Dictionary<string, int> map = new();`.
> - Collection expressions требуют целевого типа, поэтому с явной типизацией они сочетаются естественно.
> - Анонимные типы запрещены. Вместо них используются `record` или именованные кортежи.
> - Лямбда, сохранённая в переменную, получает явный тип делегата (`Func<>`, `Action<>`, собственный `delegate`).
> - Параметры лямбд в аргументах методов (LINQ) выводятся из контекста. Это не объявление переменной.

## 5. Каталог идиом: было → стало

### 5.1 Файл и проект

**File-scoped namespace (C# 10)**

```csharp
// Было
namespace Shop.Orders
{
    public sealed class OrderService
    {
    }
}

// Стало
namespace Shop.Orders;

public sealed class OrderService
{
}
```

**Implicit / global usings (C# 10).** В `.csproj` включается `<ImplicitUsings>enable</ImplicitUsings>`. Дополнительные пространства имён добавляются один раз, а не в каждом файле:

```xml
<ItemGroup>
  <Using Include="System.Collections.Frozen" />
</ItemGroup>
```

или `global using System.Collections.Frozen;`

**Top-level statements (C# 9)**

```csharp
// Program.cs. Было: class Program { static async Task Main(string[] args) { ... } }
WebApplicationBuilder builder = WebApplication.CreateBuilder(args);
builder.Services.AddSingleton(TimeProvider.System);

WebApplication app = builder.Build();
app.MapGet("/health", () => Results.Ok());
await app.RunAsync();
```

**File-based apps (.NET 10 SDK).** Для скриптов и утилит вместо отдельного проекта используется один файл:

```csharp
#!/usr/bin/env dotnet
#:package Humanizer@2.14.1

using Humanizer;

TimeSpan duration = TimeSpan.FromMinutes(95);
Console.WriteLine(duration.Humanize());
```

Запуск: `dotnet run hello.cs`.

### 5.2 Типы и члены

**Primary constructors (C# 12)**

```csharp
// Было
public sealed class OrderService
{
    private readonly IOrderRepository _repository;
    private readonly TimeProvider _timeProvider;

    public OrderService(IOrderRepository repository, TimeProvider timeProvider)
    {
        _repository = repository;
        _timeProvider = timeProvider;
    }

    public Task<Order?> FindAsync(Guid id, CancellationToken cancellationToken)
    {
        return _repository.FindAsync(id, cancellationToken);
    }
}

// Стало
public sealed class OrderService(IOrderRepository repository, TimeProvider timeProvider)
{
    public Task<Order?> FindAsync(Guid id, CancellationToken cancellationToken) =>
        repository.FindAsync(id, cancellationToken);

    public bool IsStale(Order order) =>
        timeProvider.GetUtcNow() - order.CreatedAt > TimeSpan.FromDays(30);
}
```

Правила и ловушки:

- Для DI-зависимостей это основной вариант.
- Параметр не является членом типа. Захваченный параметр хранится в скрытом изменяемом поле, поэтому ему ничего не присваивают.
- Публичное состояние объявляется явно: `public string Name { get; } = name;`.
- Валидация и `readonly`-гарантии делаются через инициализаторы:

```csharp
public sealed class Customer(string name, int age) : Entity(Guid.NewGuid())
{
    public string Name { get; } = !string.IsNullOrWhiteSpace(name)
        ? name
        : throw new ArgumentException("Name is required.", nameof(name));

    public int Age { get; } = age is >= 0 and <= 150
        ? age
        : throw new ArgumentOutOfRangeException(nameof(age));
}

public abstract class Entity(Guid id)
{
    public Guid Id { get; } = id;
}

public readonly struct Temperature(double celsius)
{
    public double Celsius { get; } = celsius;
    public double Fahrenheit => Celsius * 9 / 5 + 32;
}
```

- Если параметр и захватывается, и инициализирует поле, компилятор предупредит. Используйте что-то одно.

**Records, `with`, `record struct` (C# 9/10)**

```csharp
public sealed record Money(decimal Amount, string Currency)
{
    public Money Add(Money other) => Currency == other.Currency
        ? this with { Amount = Amount + other.Amount }
        : throw new InvalidOperationException("Currency mismatch.");
}

public readonly record struct Point(double X, double Y);

Money price = new(100m, "EUR");
Money doubled = price with { Amount = price.Amount * 2 };
```

Для неизменяемых моделей и DTO используются records, а не классы с ручным `Equals` и `GetHashCode`.

**`required` + `init` (C# 11/9)**

```csharp
public sealed class CreateUserRequest
{
    public required string Email { get; init; }
    public required string DisplayName { get; init; }
    public string? PhoneNumber { get; init; }
}

CreateUserRequest request = new()
{
    Email = "anna@example.com",
    DisplayName = "Anna",
};
```

**Ключевое слово `field` (C# 14).** Для свойства с полем-хранилищем можно задать тело одного или обоих аксессоров, не объявляя поле вручную.

```csharp
// Было
private string _name = string.Empty;
public string Name
{
    get => _name;
    set => _name = value.Trim();
}

// Стало
public string Name
{
    get;
    set => field = value.Trim();
} = string.Empty;

public int Quantity
{
    get;
    set => field = value >= 0 ? value : throw new ArgumentOutOfRangeException(nameof(value));
}
```

> [!warning] Конфликт имён
> Если в классе уже есть член с именем `field`, используйте `@field` или `this.field`.

**Partial-свойства (C# 13), partial-конструкторы и события (C# 14).** Нужны в основном для source generators:

```csharp
public partial class AppSettings
{
    public partial string ConnectionString { get; set; }
}

// сгенерированная часть
public partial class AppSettings
{
    private string _connectionString = string.Empty;

    public partial string ConnectionString
    {
        get => _connectionString;
        set => _connectionString = value;
    }
}
```

**Пользовательские составные операторы (C# 14).** Нужны для «тяжёлых» типов (матрицы, большие числа), чтобы `+=` изменял объект на месте, а не создавал новый:

```csharp
public sealed class Accumulator
{
    public long Total { get; private set; }

    public void operator +=(long amount) => Total += amount;
}

Accumulator accumulator = new();
accumulator += 5;
```

### 5.3 Коллекции

**Collection expressions (C# 12)**

```csharp
int[] first = [1, 2];
int[] second = [3, 4];

// Было
int[] primes = new int[] { 2, 3, 5, 7 };
List<string> names = new List<string> { "Anna", "Boris" };
IEnumerable<int> nothing = Enumerable.Empty<int>();
string[] noStrings = new string[0];
List<int> merged = first.Concat(second).ToList();

// Стало
int[] primes = [2, 3, 5, 7];
List<string> names = ["Anna", "Boris"];
IEnumerable<int> nothing = [];
string[] noStrings = [];
List<int> merged = [.. first, 0, .. second];   // spread
```

Другие контексты, где работает целевой тип:

```csharp
List<string> roles = isAdmin ? ["admin", "user"] : ["user"];
PrintAll(["a", "b"]);                                    // void PrintAll(IReadOnlyList<string> items)
public IReadOnlyList<string> GetNames() => ["Anna", "Boris"];
ImmutableArray<int> frozen = [1, 2, 3];
ReadOnlySpan<byte> pngSignature = [0x89, 0x50, 0x4E, 0x47]; // без аллокации
```

Допустимые целевые типы:

- массивы;
- `Span<T>` и `ReadOnlySpan<T>`;
- `List<T>`;
- `IEnumerable<T>`, `IReadOnlyCollection<T>`, `IReadOnlyList<T>`, `ICollection<T>`, `IList<T>`;
- типы с `Add` и `IEnumerable`;
- типы с `[CollectionBuilder]`.

Ограничения:

- У выражения нет собственного типа, поэтому `["a"].ToFrozenSet()` не скомпилируется:

```csharp
string[] methods = ["GET", "HEAD", "OPTIONS"];
FrozenSet<string> safeMethods = methods.ToFrozenSet(StringComparer.OrdinalIgnoreCase);
```

- Отдельного синтаксиса для словарей в C# 14 нет. Используется инициализатор с индексатором:

```csharp
Dictionary<string, int> limits = new()
{
    ["free"] = 10,
    ["pro"] = 100,
};
```

**`params` для коллекций и span (C# 13)**

```csharp
// Было: static int Sum(params int[] values) — аллокация массива на каждый вызов
static int Sum(params ReadOnlySpan<int> values)
{
    int total = 0;
    foreach (int value in values)
    {
        total += value;
    }
    return total;
}

int a = Sum(1, 2, 3);
int b = Sum([1, 2, 3]);
```

Доступны также `params IEnumerable<T>`, `params List<T>`, `params IReadOnlyList<T>`.

**Индексы и диапазоны (C# 8)**

```csharp
string[] items = ["a", "b", "c", "d"];

string last = items[^1];                 // было: items[items.Length - 1]
string[] firstThree = items[..3];        // было: items.Take(3).ToArray()
string[] middle = items[1..^1];
```

В инициализаторах доступен неявный индекс (C# 13): `Countdown countdown = new() { Buffer = { [^1] = 0, [^2] = 1 } };`

### 5.4 Строки

```csharp
// Интерполяция вместо Format и конкатенации
string message = $"User {user.Name} ({user.Id}) logged in at {timestamp:O}";

// Constant-интерполяция (C# 10)
const string Prefix = "api";
const string Route = $"{Prefix}/v1";

// Управляющая последовательность ESC (C# 13)
string red = "\e[31mError\e[0m";             // было "\u001b[31m..."

// UTF-8 литералы (C# 11)
ReadOnlySpan<byte> header = "HTTP/1.1"u8;     // было Encoding.UTF8.GetBytes("HTTP/1.1")

// Разбор строки
string[] parts = line.Split(',', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);
bool hasAt = email.Contains('@');             // char-перегрузка вместо строки
```

**Raw string literals (C# 11).** Они заменяют `@"..."` с удвоенными кавычками и конкатенацию многострочных строк:

```csharp
// Было
string json = @"{
  ""name"": ""Anna"",
  ""roles"": [""admin"", ""user""]
}";

// Стало: отступ задаёт закрывающая """
string json = """
    {
      "name": "Anna",
      "roles": ["admin", "user"]
    }
    """;

// Интерполяция: $$ означает, что значения подставляются через {{ }}, а одиночные { } — буквальные
string body = $$"""
    {
      "id": {{id}},
      "name": "{{name}}"
    }
    """;

// Однострочный вариант удобен для регулярных выражений
string pattern = """^\d{3}-\d{4}$""";
```

Переводы строк внутри `{ }` интерполяции (C# 11) нужны, чтобы выражения вроде `switch` не превращались в нечитаемую строку.

### 5.5 Null-безопасность и guard-проверки

Проект собирается с `<Nullable>enable</Nullable>`. Оператор `!` не используется. Вместо него применяются `required`, `[MemberNotNull]`, `is not null` и `?? throw`.

```csharp
// Было
if (customer != null && customer.Address != null) { city = customer.Address.City; }
if (_items == null) { _items = new List<string>(); }

// Стало
string? city = customer?.Address?.City;

private List<string>? _items;
public IReadOnlyList<string> Items => _items ??= [];

if (value is null) { /* ... */ }
if (value is not null) { /* ... */ }      // вместо == null / != null
```

**Null-conditional assignment (C# 14)**

```csharp
// Было
if (customer is not null)
{
    customer.Order = GetCurrentOrder();
}

// Стало (правая часть не вычисляется, если customer == null)
customer?.Order = GetCurrentOrder();
customer?.Total += 10m;
orders?[0] = latest;
```

Операторы `++` и `--` с этой формой не поддерживаются.

**Guard-хелперы BCL**

```csharp
public void Register(User user, string email, int retries)
{
    // Было: if (user == null) throw new ArgumentNullException(nameof(user)); ...
    ArgumentNullException.ThrowIfNull(user);
    ArgumentException.ThrowIfNullOrWhiteSpace(email);
    ArgumentOutOfRangeException.ThrowIfNegativeOrZero(retries);
    ObjectDisposedException.ThrowIf(_disposed, this);
}
```

Имя аргумента подставляется автоматически через `CallerArgumentExpression`, поэтому `nameof` не нужен.

С включёнными nullable-аннотациями проверка не-nullable параметров внутренних типов избыточна. Её оставляют на границах публичного API.

**Атрибуты nullable-анализа**

```csharp
public bool TryFind(int id, [NotNullWhen(true)] out User? user)
{
    user = _users.GetValueOrDefault(id);
    return user is not null;
}
```

### 5.6 Pattern matching

```csharp
// as + проверка → type pattern
if (shape is Circle circle) { Console.WriteLine(circle.Radius); }

// ранний выход с «отрицательным» паттерном
if (value is not string text)
{
    return;
}
Console.WriteLine(text.Length);          // text гарантированно присвоена

// switch-выражение вместо switch-оператора с return в каждой ветке
static double Area(Shape shape) => shape switch
{
    Circle c => Math.PI * c.Radius * c.Radius,
    Rectangle { Width: double w, Height: double h } => w * h,
    null => throw new ArgumentNullException(nameof(shape)),
    _ => throw new NotSupportedException($"Unknown shape: {shape.GetType().Name}"),
};

// relational + logical patterns (C# 9)
static string Classify(int score) => score switch
{
    < 0 or > 100 => throw new ArgumentOutOfRangeException(nameof(score)),
    < 50 => "fail",
    < 75 => "pass",
    _ => "excellent",
};

bool isLower = ch is >= 'a' and <= 'z';

// extended property patterns (C# 10)
// было: order is { Customer: { Address: { City: "Berlin" } } }
bool isBerlin = order is { Customer.Address.City: "Berlin" };

// list patterns (C# 11)
static string Describe(int[] numbers) => numbers switch
{
    [] => "empty",
    [int single] => $"one: {single}",
    [int first, .., int last] => $"{first}..{last}",
};

// tuple pattern для конечных автоматов
static string Next(State state, Command command) => (state, command) switch
{
    (State.Idle, Command.Start) => "running",
    (State.Running, Command.Stop) => "idle",
    _ => throw new InvalidOperationException($"{state} + {command}"),
};
```

Паттерн `var x` не используется. Вместо него применяются типизированные паттерны (`double w`, `int single`).

### 5.7 Extension members (C# 14)

```csharp
// Было
public static class EnumerableExtensions
{
    public static bool IsEmpty<T>(this IEnumerable<T> source) => !source.Any();
}

// Стало: extension-блок
public static class EnumerableExtensions
{
    extension<T>(IEnumerable<T> source)
    {
        public bool IsEmpty => !source.Any();                 // extension-свойство

        public IEnumerable<T> Exclude(T item) =>
            source.Where(x => !EqualityComparer<T>.Default.Equals(x, item));
    }

    extension<T>(IEnumerable<T>)                              // статические члены «типа»
    {
        public static IEnumerable<T> None => [];
    }
}

bool empty = numbers.IsEmpty;
IEnumerable<int> none = IEnumerable<int>.None;
```

Правила:

- Новые расширения пишутся в `extension`-блоках. Классический `this`-синтаксис считается устаревшим, но остаётся валидным.
- Блок задаёт расширения для экземпляров или для самого типа, а также статические расширения-операторы.
- Собственный член типа всегда приоритетнее расширения с той же сигнатурой.

### 5.8 Лямбды, делегаты, локальные функции

```csharp
// Было
Func<int, int> square = delegate (int x) { return x * x; };

// Стало
Func<int, int> square = x => x * x;
Func<string, bool> isLong = static s => s.Length > 10;   // static: запрет случайного захвата

// Значения по умолчанию в параметрах лямбд (C# 12)
delegate string Greeter(string name, string greeting = "Hello");
Greeter greet = (string name, string greeting = "Hello") => $"{greeting}, {name}!";

// Модификаторы без указания типов (C# 14)
delegate bool TryParse<T>(string text, out T result);
// было: (string text, out int result) => int.TryParse(text, out result)
TryParse<int> parse = (text, out result) => int.TryParse(text, out result);

// Discards
Func<int, int, int> first = (a, _) => a;
```

Локальная статическая функция вместо лямбды в переменной (нет аллокации делегата, есть полная сигнатура):

```csharp
public static IEnumerable<int> Evens(int[] source)
{
    ArgumentNullException.ThrowIfNull(source);   // проверка выполняется сразу, а не при первом MoveNext
    return Iterate(source);

    static IEnumerable<int> Iterate(int[] items)
    {
        foreach (int value in items)
        {
            if (value % 2 == 0)
            {
                yield return value;
            }
        }
    }
}
```

### 5.11 Асинхронность и конкурентность

```csharp
// Lock (C# 13 / .NET 9): вместо lock (object)
public sealed class Counter
{
    private readonly Lock _gate = new();
    private int _value;

    public int Increment()
    {
        lock (_gate)               // компилятор использует Lock.EnterScope()
        {
            return ++_value;
        }
    }
}
```

> [!warning]
> Не приводите `Lock` к `object`: оптимизация теряется.

**Async-LINQ в BCL (.NET 10).** В .NET 10 появился класс `AsyncEnumerable` с полным набором LINQ-методов для `IAsyncEnumerable<T>`, и он заменяет пакет `System.Linq.Async` от сообщества. Прямую ссылку на `System.Linq.Async` нужно убрать, иначе возможны ошибки неоднозначности.

```csharp
IAsyncEnumerable<Order> orders = repository.StreamAsync(cancellationToken);
List<Order> expensive = await orders
    .Where(o => o.Total > 1_000m)
    .ToListAsync(cancellationToken);
```

Для всех асинхронных методов действует правило: `CancellationToken` принимается и пробрасывается дальше.

## 6. Когда современный синтаксис применять не нужно

- **Primary constructor:** если нужен явный `readonly`-контроль или несколько конструкторов с разной логикой, выбирайте обычный конструктор или поле-инициализатор.
- **`field`:** если backing-поле нужно другим членам класса, объявите его явно. Ключевое слово видно только внутри аксессоров.
- **Collection expressions:** там, где целевой тип не поддерживается (например, `Dictionary`), или где `.ToList()` в конце длинной цепочки читается лучше. За это отвечает значение `dotnet_style_prefer_collection_expression`.
- **Pattern matching:** глубоко вложенные `switch`-выражения выносите в отдельные методы.
- **Raw strings:** помните, что отступ определяет закрывающая `"""`. Ошибка в отступе даёт ошибку компиляции или лишние пробелы.
- **Span:** `ref struct` по-прежнему нельзя держать через `await`.
- **`Lock`:** внутри `lock` нельзя `await`. Для асинхронных сценариев используйте `SemaphoreSlim`.
- **Рефакторинг:** не переписывайте нетронутый код только ради синтаксиса.

## 7. Чек-лист ревью

- [ ] Нет `var` (в `foreach`, `using`, `out`, деконструкции, паттернах)
- [ ] Нет анонимных типов (используются record или кортеж)
- [ ] `namespace X;`, нет лишних `using` (работают implicit/global usings)
- [ ] Конструкторы, лишь присваивающие поля, заменены primary constructors
- [ ] Коллекции создаются через `[...]`, `[.. a, .. b]`, `[]`
- [ ] Многострочные и «экранированные» строки оформлены raw string literals
- [ ] Нет `== null` / `!= null`, нет `!`; используются `is null`, `?.`, `??`, `??=`
- [ ] Guard-проверки через `ThrowIf*`
- [ ] Ветвление по типу и значению оформлено паттернами и switch-выражениями
- [ ] `using`-объявления вместо `using { }`
- [ ] Новые расширения написаны `extension`-блоками; свойства с логикой в аксессорах используют `field`
- [ ] Время берётся из `TimeProvider`, блокировки через `Lock`
- [ ] Для `IAsyncEnumerable<T>` нет зависимости на `System.Linq.Async`
- [ ] Сборка без предупреждений при `TreatWarningsAsErrors`
