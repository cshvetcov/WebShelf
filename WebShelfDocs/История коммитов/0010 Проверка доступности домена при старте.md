# 0010 — Проверка доступности домена при старте

- **Хеш:** `555e3cf`
- **Дата:** 2026-10-25
- **Автор:** Constantine
- **Сообщение:** Небольшие усовершенствования
- **Изменено файлов:** 5

## Суть изменений

- `Data.TryInitDomain` после создания `Domain` проверяет доступность контроллера домена: валидация сервисной учётной записи в режиме без GUID (`guid:false`).
- При недоступности домена объект обнуляется, чтение конфигурации завершается ошибкой — приложение не стартует с «полурабочей» конфигурацией.
- Явное использование `LogEventLevel` вместо квалификации `Serilog.Events` в настройках логгера.

## Затронутые файлы

- `WebShelf/Classes/Service/Data.cs` — проверка доступности домена.
- `WebShelf/Program.cs` — алиасы уровней логирования.
