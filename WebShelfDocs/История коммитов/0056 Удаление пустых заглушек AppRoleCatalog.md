## Суть изменений

- Удалены два файла-заглушки, оставшиеся с перехода на новую ролевую модель: `WebShelf/Classes/Security/AppRoleCatalog.cs` (8 строк) и `WebShelf.Tests/AppRoleCatalogTests.cs` (9 строк). Оба файла не содержали кода — только комментарий-пояснение, зачем заглушка оставлена, и прямую просьбу «Удалите заглушку из репозитория: git rm …».

С шага 8 декомпозиции патчи содержат полный unified diff, удаления поддерживаются — ограничение снято.
- Дорожная карта (шаг 9) прямо требовала удалить тестовую заглушку `AppRoleCatalogTests.cs` отдельным коммитом с записью в историю. Производственная заглушка `AppRoleCatalog.cs` — артефакт той же природы (пустой файл, просит `git rm`, ссылок в решении нет — проверено поиском по всему решению), удалена тем же коммитом; отступление от буквы плана (план называл только тестовую заглушку) зафиксировано в дорожной карте.
- Поведение и покрытие не меняются: файлы содержали только комментарии, тестов в заглушке нет — число тест-кейсов не изменилось (368), состав покрытия роли перечислен в комментарии удалённой заглушки и живёт в `RoleCatalogTests`, `RoleResolverTests`, `RoleResolutionTests`, `RoleCacheTests`, `RoleCacheOptionsTests`, `RoleChangeNotifierTests`, `RoleRefreshServiceTests`, `ClaimsPrincipalExtensionsTests`.
