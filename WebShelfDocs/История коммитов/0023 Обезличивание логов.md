# 0023 — Обезличивание логов

- **Хеш:** `0f32582`
- **Дата:** 2026-10-28
- **Автор:** Константин Швецов
- **Сообщение:** Из логов убраны имена пользователей
- **Изменено файлов:** 5

## Суть изменений

- Реальные имена учётных записей убраны из логов `Domain`: сервисная учётная запись обозначается `SystemAccount`, пользователь — `UserAccount` (метка выбирается по типу проверки).
- Обезличивание распространено на `Data` (вместо расшифровки логина сервисной УЗ для лога — метка `SystemAccount`) и `LoginGuard` (ключи состояния `user:<логин>` в сообщениях заменяются на `user:UserAccount`; IP клиента сохраняется).
- Исключена утечка логинов через сообщения «Начало проверки учётных данных», «Неверные учётные данные» и т.п.

## Затронутые файлы

- `WebShelf/Classes/DC/Domain.cs` — обезличивание логов.
- `WebShelf/Classes/Service/Data.cs`, `LoginGuard.cs`, `Program.cs` — обезличивание в остальных сообщениях.
