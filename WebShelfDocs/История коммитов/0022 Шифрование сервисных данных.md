# 0022 — Шифрование сервисных данных

- **Хеш:** `0f83208`
- **Дата:** 2026-10-27
- **Автор:** Constantine
- **Сообщение:** Добавлено шифрование сервисных данных
- **Изменено файлов:** 2

## Суть изменений

- `Domain` хранит логин и пароль сервисной учётной записи только в зашифрованном виде (`_encryptedUser` / `_encryptedPassword`); открытые значения получаются расшифровкой при каждом обращении (`GetDecryptedUser` / `GetDecryptedPassword`).
- Конструктор принимает зашифрованные значения и проверяет возможность их расшифровки; `Data` шифрует значения из `Server.conf` перед созданием `Domain`.
- В документацию класса добавлены remarks о хранении только шифрованных данных.

## Затронутые файлы

- `WebShelf/Classes/DC/Domain.cs` — шифрованные поля, расшифровка по требованию.
- `WebShelf/Classes/Service/Data.cs`, `Program.cs`, `Server.conf.template` — шифрование при инициализации.

> **Дополнение (2026-11-04, шаг 4 декомпозиции):** криптографическое ядро, выполняющее это шифрование (AES-256-CBC + HMAC-SHA256, Encrypt-then-MAC, формат «версия | IV | ciphertext | MAC»), после выноса из `EncryptionService` расположено в `WebShelf/Classes/Crypto/CryptoEngine.cs` (вызовы — через фасад `EncryptionService` до шага 8). Криптоформат не изменился — зафиксирован эталонной константой. См. [[0049 Криптографический движок CryptoEngine|коммит 49]].
