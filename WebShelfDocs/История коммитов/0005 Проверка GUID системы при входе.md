# 0005 — Проверка GUID системы при входе

- **Хеш:** `b1e7c1c`
- **Дата:** 2026-09-18
- **Автор:** Константин Швецов
- **Сообщение:** Изменен класс Domain
- **Изменено файлов:** 2

## Суть изменений

- `Domain.ValidateAdCredentials` получила параметр `guid` (по умолчанию `true`): после проверки логина/пароля дополнительно читается атрибут `info` учётной записи пользователя и сравнивается с GUID системы из конфигурации.
- Для чтения атрибута используется сервисная учётная запись (`PrincipalContext` с логином/паролем сервиса).
- При `guid=false` выполняется только проверка логина/пароля — режим для проверки самой сервисной учётной записи.

## Затронутые файлы

- `WebShelf/Classes/DC/Domain.cs` — параметр `guid`, проверка атрибута `info`.
